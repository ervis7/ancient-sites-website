# Ancient Sites Website

This is a web development project focused on presenting ancient historical sites and archaeological locations.

## Project Description

The project was created to present historical and archaeological locations in a clear and organized way. It combines my interest in ancient history with my interest in web development and practical project creation.

## Project Type

Web Development Project  
Computer Science / Personal Project

## Technologies Used

- HTML
- CSS
- JavaScript

## Main Features

- Presentation of ancient historical sites
- Organized website structure
- Informational content about archaeological locations
- Simple and user-friendly design

## What I Learned

Through this project, I practiced basic web development, website structure, content organization, and the creation of a practical website based on a subject that interests me personally.
